موقع تعريفي ثابت جاهز للرفع على GitHub Pages.

طريقة النشر:
1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub أو مجلد الموقع.
2) تأكد أن index.html في المسار الرئيسي الذي تنشره GitHub Pages.
3) من Settings > Pages اختر الفرع main والمجلد /root (أو المجلد الذي رفعت إليه الملفات).

الصور المرفقة هي الصور الأصلية التي أرسلها المستخدم. لا توجد قاعدة بيانات أو نموذج طلب متصل بخادم في هذه النسخة.
بيانات الهاتف والعنوان لم تضاف لعدم تأكيدها. زر التواصل يفتح رابط منشور فيسبوك المرسل.
